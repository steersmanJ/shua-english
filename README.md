# 📖 수아의 책 속 영어 모험 (Sua's Book Adventure)

초등학교 2학년 수아를 위한 AI 인터랙티브 영어 동화 학습 웹 애플리케이션입니다.  
수아가 좋아하는 고양이, 동물과의 대화(《동물과 말하는 아이 릴리》), 요괴 돌보기(《요괴의 아이를 돌봐드립니다》), 그리고 수아의 창작 캐릭터인 **'캣울프(Cat-Wolf)'** 세계관을 테마로 제공합니다.

---

## 🌟 주요 기능 및 놀이 모드

1. **📖 1. 스토리북 모험 (Story Quest)**
   - 고품질 AI 동화 삽화(수채화풍)와 함께 펼쳐지는 상황별 영어 듣기(TTS) & 말하기(마이크) 인터랙션
   - 초2 눈높이에 맞춘 필수 어휘 및 안심 선택지 분기
2. **🔍 2. 그림 속 숨은 단어 찾기 (I-Spy Detective)**
   - 영어를 듣고 AI 일러스트 안의 대상(슈미트 부인 고양이, 빨간 사과, 은빛 보름달 등)을 직접 터치하여 단어 보물 획득
3. **🎨 3. AI 마법 그림 공방 (Magic Prompt Crafter)**
   - [누가?] + [어디서?] + [무엇을 해?] 단어 블록을 조립하여 나만의 마법 주문을 만들고 창작 카드를 소환
4. **⚡ 4. 동물 & 요괴 마법 주문 배틀 (Speed Quiz)**
   - 캐릭터 고유 소리(Purr vs Bark 등)와 행동 특징을 맞히며 우정 게이지 100% 충전
5. **💾 자동 저장 (`localStorage`)**
   - 로그인이나 데이터베이스 없이도 수아의 진도, 찾은 보물 개수, 획득한 뱃지가 브라우저에 자동 영구 저장

## 🚀 배포 (Vercel)

본 프로젝트는 순수 정적 웹(Pure Static HTML/CSS/JS)으로 구성되어 있어, **Vercel 무료(Hobby) 계정**에서 영구 무료로 배포할 수 있습니다.

### 배포 방법
1. GitHub 저장소 연동: [steersmanJ/shua-english](https://github.com/steersmanJ/shua-english.git)
2. [Vercel Dashboard](https://vercel.com)에서 **`Add New Project`** 클릭 후 `shua-english` 선택
3. 별도 빌드 설정 없이 **`Deploy`** 클릭 1회로 배포 완료!
